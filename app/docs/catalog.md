The Catalog contains manufacturer and product definitions. It is the source from which physical inventory items are created. {% .lead %}

## Synchronize the catalog

Select **Catalog** from the top navigation bar. The manufacturer list appears in the left pane. When the synchronization prompt is shown, press **Synchronize** to retrieve the latest shared catalog updates, as illustrated in Figure 1.

{% figure src="/docs-placeholder.svg" alt="Catalog synchronization prompt and manufacturer list." caption="Figure 1: Catalog synchronization prompt and manufacturer list." /%}

Synchronization should be performed before adding a product manually. This reduces duplicate entries and helps maintain consistent manufacturer and model names.

## Browse and search products

Use the filter field in the left pane to locate a manufacturer, or select the manufacturer directly. The main pane lists the products associated with that manufacturer. A product entry can include a name, short description, product number, specifications, and an image, as shown in Figure 2.

{% figure src="/docs-placeholder.svg" alt="Products listed for a selected manufacturer." caption="Figure 2: Products listed for a selected manufacturer." /%}

The export icon at the right side of a product row is used to prepare that product for addition to the inventory. The catalog product is a reusable definition; the resulting inventory entry represents a physical unit.

## Add or edit a manufacturer

To add a manufacturer, select **Add manufacturer** at the bottom of the manufacturer list. Enter the manufacturer name and the available descriptive information. A website, logo, and description can be added where supported by the deployed version.

To edit an existing manufacturer, select it and use **Edit**. Avoid creating a second manufacturer entry for spelling, punctuation, or capitalization differences.

## Add a product

Select the manufacturer and press **Add Product**. The current form contains the following fields:

- **Name**;
- **Subtitle** (short description);
- **Product number**;
- **Description** (optional); and
- **Image URL**.

Figure 3 shows the product-entry form.

{% figure src="/docs-placeholder.svg" alt="Form used to add a product to a manufacturer catalog." caption="Figure 3: Form used to add a product to a manufacturer catalog." /%}

Use the manufacturer's official model designation where possible. Put stable information in the catalog product and unit-specific information in the inventory item. For example, the product can identify the model family, while the inventory item identifies a particular serial number, calibrated range, or installed option set.
