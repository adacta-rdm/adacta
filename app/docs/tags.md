title: Tags
---

The **Tags** view lists the tags available in the database and provides a field for adding a new tag. Enter a unique name and press **Add**, as shown in Figure 20. {% .lead %}

{% figure src="/docs-placeholder.svg" alt="Tags view with the existing tag list and the Add control." caption="Figure 20: Tags view with the existing tag list and the Add control." /%}

Some entries are marked **PID**. These tags are used as process-flow or P&ID node types and can appear in the facility-flowchart palette. Use concise, stable names and search the existing list before creating a new tag to avoid duplicates.

Tags provide classification and flowchart vocabulary; they do not replace the primary traceability relationships. Continue to use inventory assignments, facility-state timestamps, resource mappings, and sample installations to document what was physically present when data were collected.
